OCTOBER 26, 2026 - MW LRM AREA BARRAGE (TEST BRANCH)

I added optional area-barrage functionality to my existing LRM system without replacing the precision lock/fire system.

I enabled opt-in barrage on standard LRM-5, LRM-10, LRM-15 and LRM-20 racks. Precision fire remains the default. While seated in the mech I select the LRM weapon group, press Z to toggle barrage for that group, aim at a ground position and fire. The server accepts the toggle only from the actual controller of that crew station and refuses mode changes mid-salvo.

I reuse CGS_Titan_Missile's existing tube order, 45-degree loft, turn-rate guidance, flight travel, server hit tracing, splash damage, heat, ammo, reload, active point defense tracking, and 100 ms replicated course corrections. Barrage snapshots the chosen world aim point before the salvo and assigns each missile a random destination within a configurable radius, default 18 metres. I prevent the current laser/follow-aim modes from retargeting a barrage missile once its target is assigned.

I added the rebindable MechMissileMode key on Z and integrated it with the current station/group firing controls. SRMs, Streak SRMs, and Warlord boss racks are not opted in.

I deliberately left the existing rocket particle assets and launch sounds unchanged for now. The first step is to confirm basic server-authoritative bombardment and matching remote trajectories before heavier smoke/flash FX work. I also have not added a replicated cockpit mode text indicator yet.
