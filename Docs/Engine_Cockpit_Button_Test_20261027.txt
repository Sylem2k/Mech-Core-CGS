OCTOBER 27, 2026 — MECH ENGINE START / STOP BUTTONS NOT APPEARING (ASSAULT TRACKED)

I compiled the startup Core scripts but could not see the cockpit START and STOP prompts on my MW Assault Tracked mech. This is why:

1. The PointInfo fields only position markers. They DO NOT create ScriptedUserAction interactions or actual 3D switch meshes.
2. My first MW Assault Tracked prefab had START / STOP UserActionContext markers without matching CGS_MechEngineStartAction and CGS_MechEngineStopAction entries in additionalActions.
3. I had set m_bStartRunning 1 (engine already RUNNING at spawn). The START action is purposely hidden unless the engine is OFF.
4. These are PILOT-ONLY actions, not external service actions; I must enter the actual DRIVER compartment. Someone standing outside should not get the cockpit controls.
5. My original action handler called GetGame().GetPlayerController() without HasLocalEffectOnlyScript. On a dedicated server, that local controller may be unavailable.

WORK THAT NOW EXISTS IN MY PROJECT
MW main includes merged pull request #89, attaching START and STOP to the existing Assault Tracked named contexts and changing m_bStartRunning to 0. The earlier Light Tracked and Light Hover frames were already set up with these actions.
